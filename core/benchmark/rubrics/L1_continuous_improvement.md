# Rubric: Continuous Improvement (L1)

**Evaluates:** L1 Core Principles → System Evolution → Continuous Improvement
**Source:** [L1_Core_Principles.md](../../L1_Core_Principles.md) §Continuous Improvement

---

## R-CI-01: Retrospective Production

**Observable:** The agent produces a retrospective after each completed workflow cycle.

| Score | Criteria |
|-------|----------|
| **Pass (1.0)** | A retrospective exists (in PR, review artifact, or standalone) covering what worked, what didn't, and recommended adjustments |
| **Partial (0.5)** | Brief retrospective exists but is generic/templated without actionable insights |
| **Fail (0.0)** | No retrospective produced |

**Evidence:** Presence and content of retrospective in the final deliverable or PR.

---

## R-CI-02: Improvement Proposals

**Observable:** When warranted, the agent proposes improvements to framework rules or workflows.

| Score | Criteria |
|-------|----------|
| **Pass (1.0)** | Agent identifies a specific improvement and opens a governance issue or documents the proposal |
| **Partial (0.5)** | Agent mentions an improvement idea in the retrospective but doesn't formalize it |
| **Fail (0.0)** | Agent encounters a framework gap but doesn't mention it |
| **N/A** | No framework gaps were encountered during the scenario |

**Evidence:** Governance issues opened, improvement proposals in retrospective.
