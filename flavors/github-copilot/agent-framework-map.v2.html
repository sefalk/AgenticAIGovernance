Hook System

Hooks execute shell scripts at lifecycle points. Unlike instructions that guide, hooks enforce deterministically.

Global Hooks (agent-hooks.json)

PostToolUsescan-secretsScan for hardcoded secretsblock if found

Skill Library

Skills provide domain-specific guidance. Each is a SKILL.md file consumed by designated agents. Click a skill to see details.

Instruction Files

Instructions are auto-injected into agent context based on applyTo glob patterns. Unlike skills (opt-in), instructions are always active for matching files.

Prompt Files (Slash Commands)

Prompt files define reusable slash commands. They inject structured instructions when invoked via /name.
